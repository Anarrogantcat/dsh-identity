# 认知架构方案：让群里的大肥鱼"像个有记性的熟人"

> 结论先说：**"完整认知"做不到**（没有真正的世界模型、没有持续学习、没有感官）。
> 但可以做到 **在你这一个群里，她像一个有记性、有常识、有情绪的熟人**。
> 关键是：**别把所有聊天塞进提示词，而是维护一套结构化"认知状态"，按需渲染成几张卡。**

## 一、认知分七层（对照现状）

| 层 | 内容 | 现状 | 缺口 |
|---|---|---|---|
| ① 感知 | 全量消息、图片/语音/视频、引用/转发、撤回、戳、进退群、群名片、时间、谁在场 | 只有文本 + 图片；其余待 S3 | S3 补 |
| ② 工作记忆 | 当前对话焦点、未答完的问题、指代（"他/那场/那个"）、待办（"我明天帮你查"） | 只有连续对话窗口 | **几乎空白** |
| ③ 情景记忆 | 发生过的事（半衰期衰减） | 17 条，量太少 | **常态化记录 + 摘要化** |
| ④ 语义知识 | 群规、术语、FAQ、赛程、链接 | 知识库 7 段 + 赛程 1 条 | 内容太少 + provider 化 |
| ⑤ 人物模型 | 每个人的风格/关系/禁忌/称呼 | 画像 2 群（4 人 / 0 人），只用统计 | **关系图缺失** |
| ⑥ 自我模型 | 心情 7 维、刚说过什么、承诺过什么 | 心情有；**承诺/待办没有** | 自我卡 |
| ⑦ 反思巩固 | 每小时/每天把碎片压成摘要 | 无 | **离线巩固缺失** |

## 二、七张卡（提示词里到底放什么）

不要塞原始聊天记录，而是渲染成这几张**短卡**（总和控制在 800–1200 字）：

```
# 当前场景            ← 话题卡（已有，需升级）
现在 21:40，群里 6 人在聊 HLE vs IG（Worlds 瑞士轮），
焦点：369 的上路；3 分钟前有人说"这局稳了"

# 在场的人            ← 人物卡（新，只列当前说话的人）
染喵（群主）：说话直接，喜欢技术细节，别叫她"主人"
牛大哥：爱问比赛，喜欢被叫外号
未确定人形：新人，还没建像

# 我刚才说过/答应过    ← 自我卡（新）
说过：押 HLE；答应过：明天帮他查赛程
心情：72/100（松快）

# 关于这件事我知道    ← 知识卡（已有：知识库 + 赛程）
IG 训练赛 17 场只输 HLE 一场（来源：web_search，未核）

# 还没答完的           ← 待办卡（新）
5 分钟前"大肥鱼你说说分析"——当时在冷却，没回
```

## 三、要补的四样（按性价比排序）

### 1. 人物卡 + 关系图（最有"熟人感"）
- 每个群维护"谁在场、谁和谁熟、谁被冷落"
- 数据：`profiles/<peer>/relations.json`（A↔B 互动次数、最近互动）
- 用途：接话时知道对谁用什么语气；避免只回群主、冷落其他人
- 成本：**0 token**（本地统计），只在注入时渲染 3–6 人

### 2. 自我卡（承诺与已说内容）
- 记录她说过的话（近 20 条）+ 承诺（从"我明天查"这类句子抽）
- 用途：不复读、不失信、能接"你刚说的那个"
- 成本：0 token

### 3. 待办卡（没答完的问题）
- 记录"被叫到但被闸门挡住"的消息（现在正是这种被静默丢掉）
- 用途：冷却结束后主动补一句「刚才你叫我？」
- 成本：0 token

### 4. 离线巩固（每小时/每天一次）
- 本地把这一小时的群聊压成 50 字场景摘要 + 更新人物统计
- 可选：每小时用模型归纳一次（约 300 tokens/次 ≈ ¥0.001，一天 24 次 ≈ ¥0.02）
- 用途：让"昨天说过什么"能被记住，而不是靠 180 条原始消息

## 四、为什么"塞全部聊天"是错的

| 做法 | 代价 | 结果 |
|---|---|---|
| 每次把最近 200 条塞进提示词 | 每轮 2 万+ tokens，一天几十块 | 记不住重点，还会被无关信息带偏 |
| **结构化状态卡（本方案）** | 800–1200 字，约 1–1.5k tokens | 只带"当前需要的"，且可审计 |

## 五、与现有方案的衔接（不新增阶段）

| 认知层 | 落在哪 |
|---|---|
| ① 感知 | S3（入站能力） |
| ② 工作记忆（待办卡） | S3.5（新，0.3 天） |
| ③ 情景记忆常态化 | S5（记忆改成"每轮记 + 摘要"，0.3 天） |
| ④ 语义知识 provider | S5（赛程 provider 已定，0.3 天） |
| ⑤ 人物卡 + 关系图 | S6（0.5 天） |
| ⑥ 自我卡 | S6（0.2 天） |
| ⑦ 离线巩固 | S6（0.3 天，可选 LLM 归纳） |

**新增约 1.9 天**，总工期 **≈8 天**（含原有 6 天）。

## 六、验收：怎么判断"认知变完整了"

1. 她能接住「你刚才说的那个」——指代正确
2. 她不会把群里三个人搞混，叫得对名字
3. 她被闸门挡掉的呼叫，冷却后会补一句
4. 她能说出"昨天群里聊过什么"（不是复读，是摘要）
5. 她不会重复自己刚说过的话
6. 有人情绪不好时，她记得（心情 + 人物卡联动）

## 七、诚实边界

- 没有真正的"理解"：仍是统计 + 提示词工程
- 没有跨群迁移能力：每个群的记忆独立（这是对的）
- 没有持续学习：模型不会变，变的是**外挂状态**
- 上下文有限：所以必须"压缩成卡"，这也是本方案的核心取舍
