# 成本策略（2026-10-26 修订：不追求无成本）

> **最新原则：体验优先，成本可控。**
> 不为了省钱牺牲回答质量；只做"零损失的优化"，并给一个**日预算上限**兜底。

## 0. 与前版的差别

| 项 | 前版（省钱优先） | 现版（体验优先） |
|---|---|---|
| 看图 | 只在被问/@时看 | **有图就看**（去重 + 每日上限仍在） |
| 心情 LLM | 事件驱动、尽量少调 | 保持每 20 条（可调到 10） |
| 离线摘要 | 本地为主，模型每天 1 次 | **每小时模型 1 次**（约 ¥0.02/天） |
| 长分析 | 分级模型，能省则省 | **不降级**，该长就长 |
| 回复长度 | 为省 token 压短 | 按**人设**决定（短是因为她是这性格） |
| 消息合并 | 为省钱 | 保留，理由是**体验**（不刷屏） |
| 预算闸 | 默认开 | 默认关，**用户自己开** |

保留的"零损失"优化（不影响体验、继续做）：
1. 命令/状态/知识/赛程走 0 token
2. 系统提示稳定化（提高缓存命中，纯赚）
3. 模板兜底（问候/提醒/闭麦提示）
4. 失败熔断（防跑飞）


## 一、先看钱花在哪（单群实测口径）

| 项 | 占比 | 说明 |
|---|---|---|
| 聊天回复（调模型） | **~85%** | 主要成本 |
| 看图（vision） | ~10% | 每张约 1.5k–3k tokens |
| LLM 心情评估 | ~3% | 每 20 条一次，约 450 tokens |
| 离线摘要 / 主动搭话 | ~2% | 可本地化 |

结论：**省钱 = 减少"不必要的模型调用" + 提高"缓存命中"，不是砍功能。**

## 二、十条不砍功能的省钱手段

| # | 手段 | 省多少 | 功能影响 |
|---|---|---|---|
| 1 | **命令/状态/知识/赛程走 0 token** | 已实现 | 无（本来就不调模型） |
| 2 | **系统提示稳定化**（不塞时间戳/随机串，变化内容放尾部） | 缓存命中 ¥0.2/M vs ¥2/M，**差 10 倍** | 无 |
| 3 | **消息合并窗口**（同一人 3–5 秒内连发 → 合成一轮） | 减少 20–40% 调用 | 无（更像人） |
| 4 | **回复长度人设化**（默认 1–2 句，事实 ≤3 句） | 输出 token 降 30–50% | 无（本来要求短） |
| 5 | **图片：按需 + 去重 + 缓存**（同图 30 分钟不重复描述；描述结果存记忆，下次直接引用） | vision 降 60%+ | 仅"不发图也描述"这种多余行为被砍 |
| 6 | **心情 LLM：事件驱动 + 阈值**（无情绪波动不调；每 20 条最多一次） | 降 50% | 无 |
| 7 | **离线摘要：本地为主**（模型每天一次，其余本地压） | 降 80% | 摘要精度略降（可接受） |
| 8 | **模型分级**（闲聊用低 reasoning/小模型；长分析才升级） | 降 30–60% | 无（分析仍给对的模型） |
| 9 | **模板兜底**（主动搭话/问候/提醒/闭麦提示 → 模板） | 降 90% 于这类 | 无（本来模板就够） |
| 10 | **失败即停**（熔断 + 预算闸 warn） | 防跑飞 | 超预算才降级（用户可关） |

## 三、必须诚实的三处「无法零成本」

| 项 | 为什么 | 怎么做到"不缩水又不太贵" |
|---|---|---|
| 看图 | 每张图必消耗 vision tokens | 只在被问/@时看 + 同图缓存 + 每日上限（功能都在，只是不主动乱看） |
| 长分析（比如复盘比赛） | 需要长上下文 | 分级模型 + 只对"要分析"的消息开长上下文 |
| 深度记忆召回 | 注入越多越贵 | 状态卡控制在 800–1200 字（已经设计好） |

> 准确表述：**能力不缩水、体验略作取舍（不主动乱看图、不主动长分析）。**

## 四、预期账（单群，每天 100 条群消息 / 她回 20 条 / 看 10 张图）

| 项 | 每天 |
|---|---|
| 聊天回复 | ¥0.15–0.3 |
| 看图（10 张） | ¥0.1–0.2 |
| 心情评估（每 20 条） | ¥0.04 |
| 每小时摘要（24 次） | ¥0.02 |
| **合计** | **≈ ¥0.3–0.6/天 → ¥10–18/月** |

预算闸（可选）建议设 **¥1.5/天**：正常用不到，跑飞时兜底。

## 五、怎么验证没缩水

1. 功能清单逐项过一遍（§5 的入站/出站/闸门/认知），确认都还在
2. 面板「用量」页看：今日金额 / 调用次数 / 缓存命中率
3. 抽 20 条真实消息对比优化前后：**回答质量、长度、是否接对话题**
4. 确认这几项没有因为省钱而失效：
   - 被叫一定回（关键体验）
   - 命令 0 token
   - 知识/赛程可查
   - 心情/记忆仍在更新
