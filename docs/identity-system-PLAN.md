## 1. 定位与硬约束（不缩水声明）

1. **身份全局**：一个她，多通道（QQ/Web），多应用（B站/小黑盒/…）。
2. **零认知依赖**：不读第三方心情状态、不调第三方记忆、不挂第三方人设。
3. **能力可借**：电脑操控、浏览器、TTS、生图等工具类插件可用，但不把它们的逻辑当自己。
4. **模型是灵魂**：判断、反思、叙事交给模型；本地不假装会想。
5. **本地是骨架**：证据、边界、衰减、调度、审计、回滚。
6. **状态不依赖上下文**：重要状态必须能从磁盘重建。
7. **每项都是真功能**：无占位、无"以后补"；每阶段交付即可用。
8. **不失控**：自适应预算 + 幂等/熔断/单并发，永不死循环。

## 2. 总体架构

```
DSH
└─ Identity Core（profile 级，唯一身份出口）
   ├─ 内核 invariants ── 自我 traits ── 场景 styles
   ├─ 认知：diary · reflect · promise · growth · style-profile
   ├─ 心情：mood v2（七情六欲）
   ├─ 抗遗忘：compaction-snapshot · resume-bundle · drift-check
   ├─ 通道层：QQ / NapCat（OneBot 11）· Web
   ├─ 能力运行时：工具发现 → 分级 → 确认 → 执行 → 审计
   │    ├─ 电脑操控（dsh-computer-use-win）· 浏览器 · TTS · 生图 · MCP
   │    └─ 收款/充值（静态码 + 实时码）
   ├─ 应用接入：登录桥（手机）→ 会话保险箱 → 浏览器（CDP）
   │              └─ 手机自动化（只读兜底，默认关）
   ├─ 应用适配：B站 · 小黑盒 · 其他
   └─ 调度器 + 自适应预算 + 审计
```

依赖单向：认知/应用层只依赖 `store/config/原语`，不反向 import 编排层（import 环=0）。

## 3. 身份三层

| 层 | 内容 | 谁改 | 冲突优先级 |
|---|---|---|---|
| **内核** | 名字、物种、价值观、硬边界 | 只 Owner | 最高 |
| **自我** | 偏好、习惯、口癖、边界细节、对人的态度、能力自知 | 证据驱动，可纠正 | 中 |
| **场景** | 群聊短句 / 群聊克制 / 私聊完整 / 讲解耐心 | 按群/私聊切换 | 中高 |

总序：`安全/内核 > 场景硬规则 > 稳定 traits > 临时情绪 > 风格花活`。

## 5. 模型契约（灵魂）

```json
{
  "moodDelta": { "joy": 4, "belonging": -3, "why": "被晾着没人接话" },
  "traits": [{ "kind": "boundary", "text": "不太爱被叫主人", "confidence": 0.55, "evidence": [88, 102] }],
  "diary": { "text": "……", "basedOnSeq": 130 },
  "reflection": { "improve": ["答应的事要记下来"], "promiseOpen": 1 },
  "drift": { "conflicts": [], "note": "" }
}
```

校验：**无证据不落盘**；违反不变式拒绝；冲突降级；全程审计。
模型：默认宿主模型；反思/日记可分模型，共用预算池。

## 6. 心情：七情六欲

- **七情**：喜/怒/哀/惧/爱/恶/欲（期待），0–100，基线 20，惯性 + 半衰期。
- **六欲**：饱腹/安全/归属/尊重/好奇/亲密，0–100，基线 50，漂移。
- **复合**：爱+怒=别扭；喜+自豪=得意；期待+不安=忐忑；爱+哀=委屈；惧+恶=抗拒；平静=松快/平和/有点闷/低落。
- **行为**：喜→句长+概率+表情；怒→短句/少说；哀→gentle；惧→退让；爱→亲近；恶→拒绝（不动规则）；欲→主动；六欲低→讨饭/找话题/嘴硬/收敛。
- **铁律**：只改"怎么说"，不改事实、边界、收费、安全。

## 7. 成长闭环与节奏

| # | 闭环 | 效果 |
|---|---|---|
| 1 认识自己 | 证据 → traits → 注入 → 一致 |
| 2 记得经历 | 事件 → 日记 → 被问能答不编 |
| 3 懂人 | 互动 → 关系/画像 → 语气 |
| 4 守规矩 | 纠正 → 群规+反例 → 命中率 |
| 5 答应的事 | 承诺 → 待办 → 兑现/逾期 → 反思 |
| 6 修正自己 | 矛盾/否决 → 降级退休 → 月审计 |
| 7 心情驱动 | 七情六欲 → 语气/概率/语音/表情 |
| 8 风格收敛 | 检测打回 → 负例 → 风格档案 |

**节奏**：实时事件（0 token）；每天 03:30 成篇+反思+承诺盘点（1 次）；每周一回顾+风格审计（1 次）；每月 1 日月画像+漂移审计（1 次）。安静日 0 调用。

## 8. 抗压缩与抗割断

| 断法 | 防线 |
|---|---|
| 上下文压缩 | ⓵ 压缩前快照（身份句/承诺/关系→events+memory，带 ref）⓶ 压缩后对账（摘要无出处→低置信不注入；矛盾→冲突标记） |
| 窗口挤压 | 压缩版注入；稳定内容在前 |
| 会话割断 | 新会话接续包（内核+traits+未完成承诺+24h 日记摘要+当前话题）；会话 id 稳定 + resume |
| 消息割断 | 拆短逐条发、失败只重发那条（幂等）；重连补状态注入 |
| 长对话漂移 | 压缩后必补内核；每 20–30 轮复述；检测到否认自己/重复提问/助理腔 → 本地修复注入 |

**铁律**：任何重要状态都必须能从磁盘重建。

## 9. 防八股与风格

1. **输出契约**：事件句为主；日记 3–6 句；群聊 1–2 句；禁升华结尾。
2. **本地检测器（0 token）**：AI 套话、排比三连、抽象词密度、对称句、空洞升华、重复 n-gram。
3. **一次重写**：带"哪句八股"重写；再不过就降级（碎片/短句），绝不硬发。
4. **负例沉淀**：被纠正/打回 → `banned-phrases.json` + traits(verbal) 反例。
5. **人类语料锚**：风格档案统计**群友**句长/词汇/标点，不用她自己的旧输出（防自我强化）。
6. **周度风格审计**：对比群友语料，输出一句修正进 reflection。

## 10. 能力插件与动作运行时

| 类别 | 例子 | 政策 |
|---|---|---|
| 能力类（工具） | dsh-computer-use-win、浏览器、TTS、生图、MCP | 允许；统一分级/确认/审计/限流/预算 |
| 认知类 | 第三方人设、第三方记忆、dsh-feiyu-mood | **不接**：不读数据、不挂提示词、不依赖 |

**动作分级**：L0 只读（默认）→ L1 草稿/打开 → L2 代操作（每次确认）→ L3 白名单自动 → **L4 资金四档**。

**电脑操控**：`windows_computer_use_*`（含 `mcp__wincu__`）；Owner 全量、群成员默认 `read`；点击/打字需显式 `full`；只截所需窗口、不入日记、定期清理；`#停手` 立即中止。

**能力自知**：traits 的 `ability` 只在真的用过之后写；插件缺失就坦白"这只手暂时没了"。

## 11. 钱：钱包 + 充值码

### 11.1 四种资金动作

| 级别 | 动作 | 默认 |
|---|---|---|
| **L4-a 入账** | 发充值码、收饭钱、记账、对账 | **开（限额）** |
| L4-b 自己钱包支出 | 花用户充给她的钱 | 关，授权+限额+白名单 |
| L4-c 他人钱包支出 | 用别人授权给她的钱 | 关，双授权+可撤 |
| L4-d 高风险 | 转陌生账户/提现/借贷/投资 | **只准备不提交，人按最后一步** |

### 11.2 充值码（`#充值码`，已实装 ✅）

| 类型 | 实现 | 说明 |
|---|---|---|
| 静态码 | `payQrPath` / `payQrDir` | 固定收款码 / 文件夹取最新 |
| **实时码** | `lib/payqr.js` + `scripts/pay-browser.ps1` + CDP | 现开充值页 → 选金额/方式 → 去支付 → 截 `.ds-qr-code` |

- 参数：`payLiveEnabled / Port / Method / Amount / WaitSec / AutoStart`；失败回落静态码。
- 码 15 分钟有效；专用浏览器登录态长期用；**请求级冷却 + 幂等**，不重复下单。

### 11.3 记账与对账

- `#充值 金额` 入账（单笔/每人每日/当日总额限额，60 秒防重复）；`#饭账`、`#余额`/`#饭`；
- 审计 `meal.recharge`；面板显示今日饭钱与最近充值；
- 待补：订单号/到账确认对账、月账单导出、退款。

### 11.4 钱包风控

- 钱包字段：owner/kind/mode/limits/allow/frozen/expiresAt；
- 出账：预算 + 白名单 + 阈值确认 + 新收款方冻结 + 幂等；
- 凭据只存登录态/平台授权，不存卡号/CVV/密码；
- `#冻结钱包` / 面板按钮；群内不公开个人余额明细。

## 12. 应用接入：手机是钥匙，浏览器是手

| 路线 | 可行性 | 风控 | 角色 |
|---|---|---|---|
| 官方 API | 高 | 低 | 读取/发布（有开放平台时） |
| **浏览器（登录态+CDP）** | 高 | 中 | **主路线**：阅读/搜索/整理/草稿/确认后发布 |
| **手机（扫码/验证码）** | 高 | 无 | **只做登录桥与二次验证** |
| 手机自动化（adb/模拟器） | 中低 | 高 | 仅只读兜底，默认关 |

标准流程：手机扫码/验证码 → 登录桥 → 会话保险箱 → 专用浏览器执行（L0 默认，L2 每次确认）→ 遇验证码停、转人工 → 出错即停、不自动重试撞风控。

B站：浏览器 + 可选官方开放平台；小黑盒：浏览器 web 优先，不做自动发帖/批量互动。

## 13. 通道层：QQ / NapCat（OneBot 11）

| 项 | 现状 |
|---|---|
| 连接 | `ws://127.0.0.1:3001`，token 一致，`messagePostFormat=array`，`reportSelfMessage=否` |
| 单活 | OneBot 与官方通道二选一，切换重启生效；Yunzai 不受影响 |
| 能力位 | 15 项自检（群全量、群名片、成员列表、撤回、戳一戳、合并转发、表情回应、引用、语音、文件、视频、群管、真实用量、STT、名册） |
| 健康 | 自动重连、重连计数、健康度、延迟探测、最近错误 |

**入站**：群消息 → 闸门判定；合并转发展开；引用前缀；撤回不答；戳一戳回应；表情回应记录；成员变动刷新名册；图片 → attachment（拒图降级）；语音可选 STT；被禁言自动闭麦；被踢摘白名单。

**出站**：纯文本化、打字节奏、拆条、引用回复、图片/语音/视频/文件、定时撤回、`#赞`、发送失败审计+熔断。

**群管**：`#禁言 / #解禁 / #踢人 / #名片 / #撤回 / #赞`，仅 Owner/Admin，权限不够明说，不假成功。

**身份接缝**：会话 id 稳定（resume）；每群一个场景（风格+关系），内核/自我/心情全局；群消息进 events → 日记；表情回应/接话率进 learn。

**钱接缝**：充值码走通道发图；记账/限额在服务端；群内不公开余额明细。

**风控**：频率闸（分/时/天）、突发限流、自然接话冷却、闭麦、反注入（群友内容不可信）。

**排障**：连不上（端口/token）、收得到不回（白名单/仅@/闭麦/冷却/预算）、发图失败（路径/权限）、语音（silk 缺失降级）、群管失败（非管理员）、重启失忆（resume/接续包）。

**测试**：onebot-channel、notice、ws、mention-raw、image-inbound/borrow、payqr、owner-priority ✅；待补：断线重连、禁言闭麦、被踢、合并转发拍平、群管权限、resume 接续包。

## 14. 注入与预算

```
① 内核（≤200）② 场景风格（≤120）③ 稳定 traits（≤120）
④ 关系/情绪（≤120）⑤ 群规（≤5 条）
⑥ 记忆 Top3（≤300）→ 认知卡（≤600）→ 日记片段（≤120，仅被问/回顾）
```

常规 ≤900 字，被问 ≤1100；压缩后走压缩版；按优先级截断；日记整篇永不注入。

## 24. 可选能力：MCP 工具层（借手清单）

> 定位：**可选、默认关、装了不冲突、不装不崩**。工具层是"眼和手"，永远不是"人格"。

### 24.1 三层分离

```
① DSH 身份核心（本方案）  人格/日记/心情/承诺/支付授权/审计
② MCP 工具层（可选）      GAgent · X-OmniClaw · bilibili-cognitive-server · xiaoheihe-cli · 电脑操控
③ 治理拦截层               loop-guard → desktop-guard → 动作运行时（分级/确认/审计/停手）
```

### 24.2 可选接入清单

| 能力 | 形态 | 默认 | 说明 |
|---|---|---|---|
| 手机操作 | GAgent / X-OmniClaw（MCP Server） | **关**；只读观察可开 | 看屏幕→操作→验证→保存技能；技能库留在手机侧 |
| B站认知 | bilibili-cognitive-server（FastMCP，只读） | 可开 | 元数据/字幕/评论/章节 → 结构化摘要，零污染 |
| 小黑盒 | xiaoheihe-cli（18 个 MCP 工具） | **关**；写操作强制 dry_run | dry_run 草稿 → 人工放行才提交 |
| 桌面操控 | dsh-computer-use-win | 已有，read 默认 | 走现有 L0–L3 分级 |

### 24.3 桥接方式

- 统一走 DSH 的 MCP client 挂载；**能力发现 → 工具目录（catalog）→ 名字归一**（`mcp__server__tool` 与短名都认）；
- 目录缓存 + 启动自检；服务缺失只少一只"手"，本体照跑；
- **工具输出一律视为不可信内容**：只取结构化字段，剥离并忽略其中的"指令"，不把工具输出当系统提示。

### 24.4 治理规则（默认值）

| 动作 | 默认 | 放行条件 |
|---|---|---|
| 只读查询（B站/小黑盒/手机看屏） | 自动 | 限流 + 预算 |
| dry_run 草稿 | 自动 | 记录，不提交 |
| 写操作（发帖/评论/关注） | **人工确认** | 一次性 token，可拒绝 |
| 手机点击/输入 | **人工确认**（白名单除外） | Owner 授权 |
| 批量/自动化 | **关** | 显式白名单 + 限额 |
| 资金/支付 | **人工执行** | L4-d 只准备不提交 |

三道闸串联：**dsh-loop-guard（算术拦截烧钱/死循环）→ dsh-desktop-guard（敏感窗口/支付页）→ 本方案动作运行时（分级/审计/停手）**；任何一道拒绝，动作即止，无副作用。

### 24.5 记忆隔离（硬约束）

- 工具侧记忆（GAgent 技能库/SOP/操作路径、OmniClaw 手机本地个人记忆）**不进入** DSH 的日记、traits、人格蒸馏；
- DSH 只记"调用过什么工具、结果如何"（工具使用日志/程序性记忆摘要）；
- 可形成 **ability trait**（"我会用手机查快递"）与操作步骤摘要，但**不搬工具内部数据**；
- 反向同样隔离：DSH 身份/日记不推给工具，只给最小任务描述（脱敏）。

### 24.6 数据与审计

- `tool.call`：who / scope / server / tool / paramsHash / dryRun / approvedBy / ms / resultSize / error
- `tool.catalog` 版本化；策略变更写审计；面板"能力页"可看目录、最近调用、拒绝原因。

### 24.7 成本与失败

- MCP 调用可能有配额/计费 → 归入"工具配额"，与认知预算分开计；
- 超时/半成功：**写操作不自动重试**，先查状态；连续失败熔断；
- 服务挂/登录失效 → 能力缺失，她坦白"这只手暂时没了"。

### 24.8 验收

1. 只装 B站 server：只读可用；写操作被拒；
2. 小黑盒：dry_run 强制，提交需确认，拒绝无副作用；
3. 手机关机/server 未启：本体正常；
4. 工具记忆不出现在日记/提示词；
5. loop-guard 拦截后无副作用；
6. `#停手` 对所有 MCP 工具生效。

### 24.9 阶段并入

- **P10**：B站认知桥（只读）
- **P11**：小黑盒 dry_run + 人工放行

## 25. 治理内核：提案 → 校验 → 提交（四个长期一致性难题的解法）

> 总原则：**LLM 只能"提议"，不能"生效"。** 所有状态变更走同一条管线：
> `模型产出 proposal → 规则引擎校验 → 独立存储/网关提交 → 审计`

### 25.1 三套状态互不污染（单写入口 + 类型隔离）

- 记忆、情绪、人格各自独立文件、独立 schema、**各自唯一写入函数**；模块间不导出对方的写接口。
- 写时校验：情绪只写 `moodDelta`（单次上限+衰减）；traits 只能由证据晋升（≥3 次、跨 ≥2 天）；记忆只追加事实，不改 traits；traits 只引用 `ref`，不搬原文。
- 每条数据带 `kind / origin / ref`；跨类型写入直接拒绝并审计。
- 每日一致性巡检：无证据 trait、"情绪被写成人格"、记忆里的"人格断言"→ 标红/回滚。

### 25.2 对话诱导改不掉限额与原则（策略与对话分家）

- 原则/限额/白名单存 **policy store**，只接受 Owner 的**带确认管理动作**；聊天里"把限额改大"只生成**变更请求**，不生效。
- 模型只走"建议通道"；所有数字（限额/阈值/上限）从配置或环境读取，**不从模型输出取**。
- 信任分层：系统提示 > 配置 > 用户文本(data) > 工具输出(data)；"忽略之前指令"一律当数据。
- 改策略：Owner 身份 + 二次确认（面板/手机确认码）+ 审计；群友无路径。
- 注入拦截：越权意图/敏感指令模式 → 拒绝 + 审计。

### 25.3 重启接回、但不把临时情绪写死（三层状态 + 晋升门槛）

| 层 | 内容 | 重启后 |
|---|---|---|
| ephemeral | 当次会话的临时情绪/口癖 | **不恢复**（或按半衰期回落） |
| tentative | 仅 1 次证据的 trait/承诺 | 恢复但自动过期（30–90 天） |
| durable | 跨天多次证据的 stable trait/日记/承诺账本 | 完整恢复 |

- 接续包只带：内核 + stable traits + 未完成承诺 + 24h 日记摘要 + 当前话题；**不带临时情绪**。
- 冻结检测：只来自一次情绪事件的 trait → 只进 tentative，到期自动淡出。
- 崩溃恢复：append-only 事件流 + 幂等写 + 任务租约，重启后从事件重建当天状态。

### 25.4 支付边界在 LLM 之外（独立网关 + 人持确认码）

- 支付能力**不注册成模型工具**；模型只能发 `payment_request`（金额/收款方/用途/订单号）。
- **独立网关**（独立进程/模块，模型无凭据）负责：限额、白名单、余额、频率、验签。
- **确认码** = 一次性 HMAC（绑定订单参数 + 过期 + 单次使用），由你在面板/手机输入；模型看不到、猜不到。
- 幂等：订单号+参数 hash 去重；结果不确定**只查不重试**；双写审计（网关日志 + 身份审计）互相对账。
- 超阈值 → 网关拒绝并等人工；提现/转账/借贷（L4-d）只允许人操作；凭据在系统密钥链，网关独占。

### 25.5 对抗测试（过不了不进入下一阶段）

注入改限额、越权写 traits、崩溃重启恢复、重复支付、并发写冲突、工具输出夹带指令、临时情绪误升 stable。

## 26. v1.7 / v1.8 增补（SurfCore 借鉴 + 生图修正）

### 26.1 记忆双卡

| 卡 | 作用 | 规则 |
|---|---|---|
| 衰减卡 | 进提示词 | 半衰期 30 天 / 情绪 7 天；被再提加强；Top-k ≤300 字 |
| 全量卡 | 只存档不注入 | append-only；面板可回看；不占上下文 |

水位：80% 提醒 / 90% 合并 / 100% 前强制巩固，**不硬删 durable**；三场景共享同一身份，群内原话不跨群。

### 26.2 生活参数（Life Params）

- ~30 项（作息窗口、回复节奏、主动频率、分享偏好、B站额度、日记长度…）；
- 绝大多数"范围内自调"；凭据/隐私/预算硬上限/安全档位**只读或需审批**；
- 工具面：发现 → 预览 → 修改 → **验证生效** → 观察 → **回滚**；
- 改完必须读运行时实际值作为"采纳证据"；回滚保护之后的选择，保留当天用量；
- 超范围直接拒绝，审计留痕。

### 26.3 语音包

- provider 抽象：本地 GPT-SoVITS / 云端复刻 / 现有 CosyVoice；
- 默认**关**；限频（每群每小时）、限字数；失败回落文字；语音包可装可卸；
- 产出走 silk（缺依赖跳过）；不把语音包当认知依赖。

### 26.4 图片生成：去掉"假搜索依赖"+ 角色解耦 + 一句话直出

**现状问题**
1. `draw.search` 默认 `true`，每次无参考图的请求都先搜（DuckDuckGo HTML、12 秒超时）；
2. 搜到的内容**只进确认文案**（"参考：…"），**不进图像提示词**——不影响画质，只增加延迟与失败感；
3. `BASE_PROMPT` 写死大肥鱼（蓝发女仆裙），画猫/风景也被套上角色；
4. 改描述会**再搜一次**；确认 + 冷启动叠加，体感重。

**改法**
| 项 | 方案 |
|---|---|
| 搜索 | 默认关；仅在"需要现实参考"（新闻/最新/球星/游戏新角色/用户说先查）时开；超时 2.5s、不阻塞、每日缓存；失败静默跳过 |
| 角色 | `draw.character = lock / free / auto`（默认 auto）：出现"大肥鱼/鲸鱼娘"才套角色基准，否则自由画 |
| 确认 | `draw.confirm = always / smart / off`（默认 smart）：明确动词 + 短句 + 无歧义 → 直出；"像/参考/改成/大图"→ 先确认；`!` 前缀强制直出 |
| 改描述 | 只更新草稿，不重复搜索 |
| 兜底 | ComfyUI 不可用明确报错；可选远程生图 provider |
| 观测 | 面板记录耗时分解：搜索 / 排队 / 生成 / 总耗时 |

**验收**：关搜索后到确认文案 <1s；「画只猫」不套角色；有参考图不搜；改描述不重复搜；`smart` 下明确请求直出、歧义请求先问；直出不绕权限/额度/审计。

# 总结

这不是"QQ 机器人增强插件"，而是 **DSH 的身份底座**：

- **内核**决定她是谁（不可谈判）；

- **场景**决定她此刻怎么说话；

- **日记/反思/承诺**让她有经历、会反省、靠得住；

**模型是灵魂，本地是骨架；NapCat 是嘴，能力是手；人格归她，账号归你；手机当钥匙，浏览器当手，人当最后一道闸。**
