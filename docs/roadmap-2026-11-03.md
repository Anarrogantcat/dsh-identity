## 阶段 1 · 主要目标（六条）

### 1. 记事

- 风险：召回预算 300 字，人和事会互相挤；分组后要盯住「人优先」（已用保底兜住）

### 2. 判断
- 现状：`judge.js` 蒸馏（一行一条、最多 3 条），写进判断卡
- 缺口：**记人已验**（12/12 轮达标）；~~判断卡不进 traits~~ 已接上认知链（1.9.224：判断卡作为 judge 旁证进 `confirmedBy`，改口进 `refutedBy`）；收口已做（见阶段 0）

### 3. 会累
- 现状：`pace.js`，3% 起、越说越贵、50 分钟回满、tone 分档；web 已补 `noteReply`
- 缺口：~~web 侧没观测到变 terse~~ 已验；**验的时候抓到真 bug**：`workMode` 把整句 tone 文案替换成「精力只当状态记着」，等于把「会累」从聊天里关掉了 → 改成只压「干活力度」、保留话短提示（1.9.226）
- 验收：✅ 2026-11-03 模拟 web 连说 20 句：第 1 句 full → 中途 terse → 落 low，精力单调下降；三档提示文案互不相同且都提「话短」；「回复确实变短」是提示词效果，得人工看（机制已证，体感未证）

### 4. 共情
- 现状：`empathy.js`，检测 5 类情绪 + 策略；QQ 与 web 都已接
- 缺口：~~web 没触发过~~ 已验；**验的时候抓到真 bug**：提示只看「最近一条」不看 outcome —— 说了「别安慰我」下一轮还在安慰 → 新增 `empathy.promptFor()`，`outcome=negative` 就不再提（1.9.227）
- 验收：✅ 2026-11-03 web 模拟三条：说难受 → 下一轮拿到「先接住情绪」；说「别安慰我」→ 那条标 negative 且不再提；再说烦 → 重新给「先确认在气什么」。`test/empathy-web-test.mjs` 7 条

### 5. 人格（灵魂）
- 现状：内核 + 自我模型 + traits（tentative→durable）；**1.9.231 起按「正常人」口径判人格**
- 晋级规则（5 条，`lib/lifecycle.js`）：
  1. **同一场合重复不算新证据**：证据按「天 × 来源」去重（`independent`），同一天说三遍只算一次
  2. **得有人认过**：`confirmedBy` 里至少一条 `by=user`，纯自我感觉不上位
  3. **承诺 / 口头禅不进人格**：`kind=promise` 或含「记得/明天/回头」这类字的，永远停在 tentative
  4. **人格是稀有的**：`durable` 上限 12 条，超了最弱的先退成 tentative（`demotedBy=cap`）
  5. **不追溯降级**：老的人格不因新规矩当场塌，只标 `stale` 等复核
- 数据（2026-11-03 21:20 实测）：durable **3**（3 条全标 stale）/ tentative 71 / retired 9 / 待复核 6——比早先记的「6 durable」更少，验收要 ≥10，差距更大
- 验收：durable ≥10 条，且没有空壳/复读——**按新节奏会更慢，得靠真实聊天攒**

### 6. 七情六欲
- 现状：`moodv2` 七情六维 + 六欲，衰减、复合、影响语气和主动概率；**1.9.232 起按「正常人」口径**
- 规则（5 条）：
  1. 一次不会炸，但会累积；有上限（不会无限升级）
  2. 没新刺激 **24 小时回落一半**（负面半衰期 36h → 24h）
  3. 负面比正面留得久（正面 12h 半衰，负面 24h）
  4. 烦了会表现在话上：进「抗拒」档，但提示里明说别骂人
  5. **道歉降火约三成**（不是清零——人不是不讲理，是气头上不讲理）
- 模拟验收：`scripts/mood-acceptance.mjs` 跑曲线；`test/mood-rules-test.mjs` 进 npm test
- 验收：曲线已跑通；还缺**真实对话样本**（至少 3 次真实被怼，记进 docs），模拟不算最终验收
