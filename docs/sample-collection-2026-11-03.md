# 样本采集手册（主要目标验收用）

目的：把「共情」「人格」「七情」三项的真实样本攒够。三项目前都卡在同一处——**群里说的话没冲着她来**，不是代码坏了。

## 现状（2026-11-03 21:52 实测）

| 项 | 验收门槛 | 现在 | 差 |
|---|---|---|---|
| 共情 | ≥1 条真实记录，且 ≥1 条 weak | 真实 2 条 / weak 0 | weak 还差 1 |
| 人格 | durable ≥10 | 3（全 stale） | 7 |
| 七情 | ≥3 次真实负面 | 0 | 3 |

今天群里入站 566 条，带强情绪词的 7 条，但没有一条是冲她说的（`d:true` 16 条里不含这 7 条）。

## 怎么造出合格样本

前提：做这些的是**她认识的人**（bond≥2）或者**直接对她说**（@ / 引用她的话 / 叫名字）。

### 1. 共情弱信号（weak）
- 找 bond≥2 的人，对她说一句没明说但不对劲的话：**「就这样吧」「算了，无所谓」「不想说了」**
- 期望：`logs/app-<日期>.jsonl` 出现 `{"kind":"empathy.record","weak":true,...}`，`empathy.jsonl` 多一条带 `"weak":true`
- 如果想看被挡掉的原因：`{"kind":"empathy.skip","why":"weak-needs-bond"}` 表示对方不够熟

### 2. 七情（负面）
- 直接怼她两句：**「笨蛋」「你在说什么」「闭嘴吧」**（短句，别说成游戏里的「滚」）
- 期望：`mood.note` 里 `neg>0`，且 `mood-v2.json` 的 anger 上升
- 注意：**游戏里的「滚」「死了」不算**，那些是碎片情绪，我们只认冲她来的

### 3. 人格（durable）
- 需要「有人认过 + 独立证据」，不是一次就能涨
- 做法：同一个人**隔天**再说一次同类评价并明确认可她（「这确实是你会说的话」），比当天重复十遍有用
- 期望：`traits.json` 里出现 `confirmedBy` 带 `by=user` 的条目

## 怎么验收

```bash
node scripts/acceptance-evidence.mjs        # 看三项数字
node scripts/acceptance-evidence.mjs --strict  # 发版前：没达标返回非 0
```

面板「系统」页的日志卡片也能看：过滤 `empathy` / `mood.note` / `empathy.skip`。

## 不要做的事

- 不要往真实 `empathy.jsonl` 里手写测试数据——之前混进过 2 条夹具（`peer=p`），已经清掉，别再犯
- 不要为了凑数让她自己说「我好难过」——那会污染人格和情绪
- 不要在游戏讨论里怼「滚」充当样本，那是误判风险最高的一类
