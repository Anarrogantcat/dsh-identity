## 二、功能缺口（按价值 / 风险排序）

### P0（影响正确性与花钱）
1. **花费硬闸**（元/天 + 超限降级）——现在只有记录
2. **真实 token 用量**（OneBot: `chat-sessions.json` → projcache）——方案已给
3. **回声抑制**（`ignoreSelf`）——同群有多机器人时会互相对话（Yunzai 同号也在群里）
4. **消息合并**（`mergeWindowSec`）——同一人连发多条，她连回多条，像刷屏

### P1（NapCat 能力兑现）
5. 撤回不答 / 戳一戳 / 合并转发 / 表情回应（入站）
6. 引用回复 / 定时撤回 / 语音 / 视频 / 文件 / 群管（出站）
7. 群名片同步 → 画像准确

### P2（体验与运维）
8. 突发限流 + 退避（`burst*`）
9. 隐私补全：外链白名单、丢链接、@昵称脱敏、入站媒体白名单、外发大小上限
10. 审计日志轮转（`auditDays`）+ 磁盘占用监控
11. 画像调度（`dailyAt`）、长期清除（`sealDays`）、首次通知（`notifyGroup`）
12. 自动撤回（`autoRecall*`）+ 闭麦模板
13. 用量：token 预算与金额预算统一（`groupDailyTokens/userDailyTokens/warnRatio`）
14. 知识库注入字数可调（`injectChars`）
15. 表情单张上限（`maxPerMsgMB`）
16. B站推送（模板/封面/pushEnabled）

### P3（增值）
17. 收集的表情**自动打情绪标签**（现在 8 张全是截图，已经标成不可发送；新的收集图还没打标机制）
18. 语音：STT 启用（dsh-onebot 自带 whisper 支持）+ TTS 部署（`voice.enabled=false`，需要服务）
19. 面板缺页：**知识库页**（现在只能改文件）、**赛程页**、**通道页**（方案 S6）
20. 表情库单点依赖 `fisharchive.cc`（可加多源/本地备份）
