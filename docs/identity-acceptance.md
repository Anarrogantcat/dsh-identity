# 验收清单：怎么判断「像人」那批改动真的生效了

不是看有没有重启，是看数据变没变。

## 重启后 1 小时内（判断蒸馏）

- `growth-status` 里「判断卡」从 0 变成 ≥1
- 审计里 `memory.judge` 的 `n` 大于 0（不是 `n:0 got:0 out:""`）
- `"out"` 字段里有 JSON 片段

失败表现：还是 `out:""` → 模型没输出正文，检查 token 或路由。

## 6 小时后（连续自我）

- `selfmodel-history.jsonl` 出现新条目，且带 `substance` 字段
- 新条目的 `summary` 以「跟上次比：」开头
- 不再出现三条一模一样、只有心情标签不同的复读

失败表现：条目数不变 → 快照被「写不出变化」挡下了，也可能是身份段注入没触发。

## 第二天（安静的时候）

- 日记的 `source` 变成 `llm`（不再是 `local` 的统计版）
- 复盘里出现「我想弄明白：……」那一行
- 早上看 `inner/` 目录有没有新的内心活动

失败表现：日记还是 4 句统计 → 模型输出空，回落了本地规则。

## 群里观察（不用重启也能看）

- 别人自述「我马上没饭吃了」→ 不接
- 别人问「这个怎么弄」→ 可以接
- 被叫名字、被 @ → 一定接
- 群友问余额 → 不报自己的钱包余额（只有主人问才报）

## 三天后（人格）

- 稳定认知从 1 条涨到 3 条以上
- 稳定认知的内容是行为经验或自我描述，不是聊天残句
- `growth-log.jsonl` 里 `durable` 是单调上升的，不是来回跳

## 怎么快速跑一遍

```bash
node scripts/check-version.mjs    # 新版加载了吗
node scripts/growth-status.mjs    # 六条链的数据
```
